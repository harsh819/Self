# Daily Application Plan (40-50/day)

Target: Backend Engineer (Node.js/NestJS, PostgreSQL, AWS), Mumbai / remote / open to relocate.
Tracker: `Job-Tracker.csv` (open in Excel). Log every application the moment you submit it.

## Daily split (~2.5-3 hrs)
| Bucket | Count | Resume | Time |
|---|---|---|---|
| Quick apply (Instahyre, Naukri, LinkedIn Easy Apply, Cutshort, Wellfound) | 30-35 | Backend master | ~1.5 hr |
| Tailored (send me the JD, I make a CV copy) | 5-8 | Tailored copy | ~45 min |
| Direct/referral (company careers page + message a recruiter or engineer) | 5-8 | Backend master | ~45 min |

Full Stack master only for React/full-stack-titled roles.

## Setup (once, ~1 hr)
1. Saved searches + email/app alerts on each platform: `Node.js developer`, `Backend engineer`, `NestJS`, `Software engineer Node`, `SDE-1/SDE-2 backend`. Filters: Mumbai, Remote, Pune, Bangalore; 2-5 yrs.
2. Naukri and Instahyre profiles fully filled; set notice period honestly (60 days) and expected CTC.
3. LinkedIn: turn on "Open to work" for recruiters only (so your current employer can't see it).
4. Keep a text file of reusable answers: CTC, expected CTC, notice period, relocation, "why this company" (2 lines), skills years.

## Daily routine
1. **Morning (20 min):** open alerts, open every relevant new listing in tabs. Skip: pure support/implementation roles, 8+ yrs, unrelated stacks.
2. **Apply block (quick apply bucket):** 30-35 applications. Log each in the tracker as you go.
3. **Tailored block:** pick the 5-8 best JDs, paste them to me, I return a tailored CV + gaps + likely questions.
4. **Outreach block:** for the 5-8 best companies, message a recruiter/engineer: 3 lines, what you built, link to GitHub. No "please refer me" cold asks.
5. **Evening (10 min):** reply to recruiter messages and calls, update tracker status, set follow-ups.

## Rules
- Priority order: product/SaaS companies first, then startups, services firms (Tier C) last.
- Never exceed what's true on the CV. Gaps get flagged, not faked.
- Don't name the client in any form field or message (confidentiality clause).
- Follow up once after 7 days; mark Ghosted after 14.
- Weekly (Sunday, 15 min): count applications, responses, interviews. If responses are under ~3%, fix the CV/profile before adding volume.

## Expect
Quick-apply response rates are low, roughly 2-5%. 40/day is about 280/week, so expect a handful of calls a week. Volume only helps if the CV matches the JD, which is why the tailored bucket matters most.

## Things not to do
Auto-apply bots or scripts on LinkedIn/Naukri: they violate the platforms' terms and can get the account restricted, which would cost you your best channel.
