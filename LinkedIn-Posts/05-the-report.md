Finding the root cause isn't enough. You have to convince someone else.

On the after-midnight shows bug, I couldn't edit the client's query myself, and a Slack message saying "I think your query is wrong" wasn't going to work after 3–4 years.

So I built a short HTML report:
• what the screen shows vs. what it should show
• the actual rows that prove it
• which part of the query causes it
• what needs to change

Once they could see it, the discussion changed from "is there a bug?" to "when can we fix it?"

Lessons:
→ Evidence beats opinion.
→ A simple report in the format people already use beats a clever tool.
→ Write it so a non-developer could follow it.

When did you last change someone's mind with evidence instead of argument?
